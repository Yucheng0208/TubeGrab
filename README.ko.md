# TubeGrab

[繁體中文](README.md) | [简体中文](README.zh-Hans.md) | [English](README.en.md) | [日本語](README.ja.md) | **한국어**

TubeGrab은 Swift와 SwiftUI로 만든 macOS용 영상·음악 다운로더입니다. 주소를 붙여넣거나 곡명을 입력하고 고르기만 하면 다운로드할 수 있도록 화면을 단순하게 만들었습니다. yt-dlp, ffmpeg 같은 오픈소스 도구를 사용하기 쉬운 Mac 앱으로 감싸는 방법을 보여 주는 학습용 예제 프로젝트입니다.

> **면책 조항**
>
> 이 프로젝트는 교육 및 예제 용도로만 제공됩니다. 본인이 저작권을 가지고 있거나, 허가를 받았거나, 다운로드가 명시적으로 허용된 콘텐츠(크리에이티브 커먼즈, 퍼블릭 도메인, 직접 업로드한 영상 등)만 다운로드하세요. YouTube, Spotify, Apple Music, KKBOX 등의 콘텐츠를 다운로드하는 것은 각 서비스의 이용 약관과 해당 지역의 저작권법을 위반할 수 있습니다.
>
> 이 소프트웨어는 '있는 그대로' 제공되며 어떠한 보증도 하지 않습니다. 사용으로 인한 모든 결과는 사용자 본인의 책임이며 작성자는 어떠한 책임도 지지 않습니다. 이 앱은 DRM을 우회하지 않습니다. Spotify, Apple Music, KKBOX에서는 곡명과 가수 목록만 읽고 YouTube에서 공개 영상을 검색합니다.

## 기능

| 기능 | 설명 |
|---|---|
| 영상·음악 다운로드 | YouTube 및 yt-dlp가 지원하는 수천 개의 사이트. 영상: MP4, MOV, MKV, WEBM (360p ~ 4K). 음악: MP3, M4A, AAC, FLAC, ALAC, WAV, OPUS, OGG |
| 곡 검색 | 곡명, 가수, 기억나는 가사 한 줄로 검색. 결과에 '공식', '추천' 표시와 미리 듣기 제공 |
| 일괄 다운로드 | YouTube 재생목록, Spotify, Apple Music, KKBOX 재생목록이나 앨범, 또는 CSV·TXT·XLSX 파일 가져오기 |
| 최적 버전 자동 선택 | 음반사나 공식 채널 영상을 우선하고, 없으면 조회수가 가장 높은 영상을 선택 |
| 곡 정보 | 파일 이름, 곡명, 가수, 앨범, 연도, 장르를 자동으로 채우고 모두 수정 가능. 웹에서 찾은 곡 정보도 참고 가능 |
| 가사 | 동기화 가사(.lrc) 다운로드, 곡 파일에 넣기, 전체 가사 내보내기, 번체·간체 변환 |
| 미리보기와 자르기 | 영상 미리보기, 일부 구간만 다운로드, 설정을 적용한 실제 결과 미리보기 |
| 오디오 도구 | 좌우 채널, 밸런스, 보컬 제거, 볼륨, 음량 평준화, 키 변경, 속도, 페이드 인·아웃 |
| 영상 처리 | 화질 개선(1080p ~ 4K로 업스케일), 화면 비율 변경(검은 여백, 흰 여백, 흐린 배경, 흐린 커버, 잘라서 채우기) |
| 악보 찾기 | 기타 타브, 코드, 오선보, 숫자보, 피아노 악보를 한 번에 검색 |
| 다운로드 목록 | 전체 및 항목별 진행률(퍼센트, 속도, 남은 시간). 취소, 다시 시도, 제거, 파일 바로 열기 |
| 인터페이스 | 繁體中文, 简体中文, English, 日本語, 한국어. 다크, 라이트, 시스템. 사용자 지정 테마 색상과 그라데이션. 글꼴, 글자 크기, 버튼 크기, 화면 배율 |
| 어떤 창 크기든 | 자유롭게 크기를 바꾸거나 전체 화면으로 사용 가능. 글자와 버튼이 창에 맞춰 바뀌고, 좁은 창에서는 세로 배치로 전환 |
| 도구 자동 설치 | yt-dlp나 ffmpeg가 없으면 한 번의 클릭으로 설치 |
| 업데이트 확인 | GitHub에서 새 버전 확인 |

## 다운로드 및 설치

1. [Releases](../../releases) 페이지에서 `TubeGrab-버전-macOS.dmg`(또는 `.zip`)를 다운로드합니다.
2. `.dmg`를 열고 **TubeGrab**을 **응용 프로그램** 폴더로 끌어다 놓습니다.
3. 처음 실행할 때는 응용 프로그램 폴더에서 TubeGrab을 **오른쪽 클릭하고 '열기'를 선택한 뒤 다시 '열기'** 를 누릅니다.
   Apple의 공증을 받지 않은 앱이라 처음 한 번 macOS가 확인을 요청합니다. 그다음부터는 더블클릭으로 열 수 있습니다.
4. '손상되었기 때문에 열 수 없습니다'라고 표시되면 터미널에서 다음을 실행하세요.

   ```bash
   xattr -dr com.apple.quarantine /Applications/TubeGrab.app
   ```

**요구 사항**: macOS 14 Sonoma 이상, Apple Silicon 및 Intel Mac 지원.

**업데이트**: 새 `.dmg`를 다운로드한 뒤 TubeGrab을 응용 프로그램 폴더로 끌어 기존 버전을 교체하세요. 설정은 유지됩니다.

## 처음 사용할 때

1. TubeGrab을 엽니다. 위쪽에 '처음 사용: 다운로드 도구가 필요합니다'가 보이면 **설치** 를 누르고 1~3분 기다립니다.
   - Homebrew가 있으면 `brew install yt-dlp ffmpeg deno`를 실행합니다.
   - Homebrew가 없으면 공식 릴리스 페이지에서 `~/Library/Application Support/TubeGrab/bin`으로 내려받습니다.
2. **모양** 에서 화면 모드, 색상, 글자 크기를 고릅니다.
3. **환경설정** 에서 언어와 저장 위치(기본값은 '다운로드' 폴더)를 고릅니다.

## 사용 방법

사이드바는 세 그룹으로 나뉩니다.

| 그룹 | 페이지 | 용도 |
|---|---|---|
| 다운로드 | 새 다운로드 | 영상 주소를 붙여넣고 형식, 미리보기, 자르기, 정보 수정 후 다운로드 |
| | 곡 검색 | 곡명이나 가수로 검색 |
| | 가사로 찾기 | 가사 한 줄만 기억날 때 |
| | 일괄 다운로드 | 재생목록 전체를 한 번에 다운로드 |
| | 다운로드 목록 | 진행 상황과 완료된 파일 |
| 설정 | 모양 | 화면 모드, 색상, 글꼴, 크기 |
| | 환경설정 | 언어, 저장 위치, 외부 도구, YouTube 로그인, API 키 |
| 지원 | 도움말 | 기능별 사용 방법(검색 가능) |
| | 정보 | 버전, 업데이트 확인, 문제 신고, 면책 조항 |

입력란에 붙여넣은 내용은 알맞은 페이지로 자동 이동합니다. 영상 하나는 새 다운로드, 재생목록 주소는 일괄 다운로드, 텍스트는 곡 검색으로 갑니다.

### 새 다운로드 (영상 또는 곡 하나)

1. YouTube 등에서 영상 주소를 복사하고 **새 다운로드** 에서 **붙여넣기** 를 누릅니다(입력란에 붙여넣고 **불러오기** 를 눌러도 됩니다). `https://`는 생략해도 됩니다.
2. **영상** 또는 **음악 (오디오만)** 을 고릅니다.
3. 형식과 품질을 고릅니다.
   - 영상: MP4, MOV, MKV, WEBM, 360p ~ 4K. Mac이나 iPhone에서 재생하려면 MP4를 권장합니다.
   - 음악: MP3, M4A, FLAC, ALAC, WAV 등. 일반 감상은 MP3 320k면 충분합니다.
4. 필요하면 아래의 오디오 도구, 자르기, 곡 정보를 조정합니다.
5. **다운로드에 추가** 를 누르고 다운로드 목록에서 진행 상황을 확인합니다.

주소 대신 글자를 입력하면 입력란 아래에 **곡명/가수** 와 **가사로** 두 버튼이 나타나며, 누르면 검색을 시작합니다.

### 미리보기, 자르기, 설정 적용 후 미리보기

- 영상을 불러오면 미리보기 플레이어가 자동으로 나타납니다.
- **일부 구간만 다운로드** 를 켜고 시작·끝을 드래그하거나, 재생 중에 **현재 위치를 시작으로** / **현재 위치를 끝으로** 를 누릅니다.
- 플레이어 위에서 **설정 적용 후** 로 바꾸면 실제 다운로드와 같은 처리로 짧은 구간(자르기 범위 최대 30초, 아니면 현재 위치부터 20초)을 만들어 형식, 오디오 도구, 화질 개선, 화면 비율의 실제 효과를 확인할 수 있습니다. **자동 갱신** 이 켜져 있으면 설정을 바꿀 때 자동으로 다시 만듭니다.
- 미리보기 아래에 저장될 파일 이름과 곡 정보가 표시됩니다.

### 파일 이름, 곡 정보, 가사 미리보기

- 파일 이름, 곡명, 가수, 앨범, 앨범 아티스트, 연도, 장르는 YouTube 정보가 기본값이며 모두 수정할 수 있고 파일 태그에 기록됩니다.
- **웹에서 찾은 곡 정보 (참고)**: Apple Music 카탈로그를 검색해 커버, 앨범, 연도, 트랙 번호가 있는 후보를 보여 줍니다. **적용** 을 눌러야 반영됩니다. **YouTube 정보로 되돌리기** 로 원래대로 돌릴 수 있습니다.
- **가사**: **가사 찾기** 로 미리 보고, 동기화와 텍스트를 전환할 수 있습니다. **가사 복사**, **.lrc 내보내기**, **전체 가사 .txt 내보내기** 를 사용할 수 있습니다.
- **악보 찾기**: 기타 타브·코드(Ultimate Guitar, 91譜), 오선보(MuseScore), 숫자보, 피아노 악보 검색 결과를 엽니다. 웹페이지만 열고 악보를 다운로드하지는 않습니다.

### 곡 검색과 가사로 찾기

1. **곡 검색** 에 '가수 곡명'을 입력합니다. **가사로 찾기** 에는 기억나는 가사 한두 줄을 입력합니다.
2. '공식'은 음반사나 가수 채널, '추천'은 앱이 고른 최적 버전입니다.
3. 썸네일의 재생 버튼으로 미리 들을 수 있으며, 아래에 재생 바가 나타납니다.
4. **선택** 을 누르면 새 다운로드로 이동해 자세히 설정하고, **음악으로 바로 받기** 를 누르면 기본 설정으로 바로 받습니다.

### 일괄 다운로드

1. **일괄 다운로드** 에 재생목록이나 앨범 주소를 붙여넣고 **불러오기** 를 누릅니다.

   | 출처 | 설명 |
   |---|---|
   | YouTube 재생목록 | `youtube.com/playlist?list=...`. `watch?v=...&list=RD...` 같은 자동 믹스는 영상 하나로 처리 |
   | Spotify | 공개 재생목록이나 앨범. API 키가 없으면 약 50~100곡까지 |
   | Apple Music | 공개 재생목록이나 앨범 |
   | KKBOX | 환경설정에 무료 KKBOX Open API 키 필요. 또는 곡 목록 붙여넣기 사용 |

2. **곡 목록 붙여넣기** 를 눌러 한 줄에 한 곡씩 입력할 수도 있습니다.

   ```text
   가수 - 곡명
   곡명 / 가수
   1. 가수 - 곡명 4:22
   ```

3. **파일 가져오기 (CSV / TXT / XLSX)** 를 누르거나 파일을 페이지에 끌어다 놓습니다. 곡명, 가수, 앨범, 길이 열을 자동으로 찾습니다(Spotify의 `Track Name`, `Artist Name(s)` 등). 제목 행이 없으면 첫 번째 열을 곡명, 두 번째 열을 가수로 봅니다.
4. 받을 곡을 체크하고 형식을 고른 뒤 **모두 자동 다운로드** 또는 **선택한 곡 다운로드** 를 누릅니다.

곡마다 YouTube에서 최적의 영상을 찾습니다. 커버, 노래방, 리믹스 등을 먼저 제외하고 '가수 - Topic' 채널, VEVO, 음반사, 가수 공식 채널을 우선하며, 모두 없을 때만 조회수가 가장 높은 영상을 고릅니다.

### 다운로드 목록

- 위쪽 원은 전체 진행률입니다. 각 항목에 퍼센트, 현재 단계, 받은 크기, 속도, 남은 시간이 표시됩니다.
- 진행 중에는 **취소**, 실패하면 **다시 시도** 또는 **신고**, 완료 후에는 썸네일이나 제목을 클릭하거나 행을 두 번 클릭해 엽니다.
- 재생할 수 있는 앱으로 자동으로 엽니다. macOS가 지원하는 형식은 기본 앱으로, MKV, WEBM, OPUS 등은 IINA나 VLC(설치된 경우)로 엽니다.
- 기본 저장 위치는 '다운로드' 폴더이며 환경설정에서 바꿀 수 있습니다.

### 오디오 도구

새 다운로드나 일괄 다운로드에서 **오디오 도구** 를 펼칩니다.

- **채널**: 스테레오, 왼쪽만, 오른쪽만, 좌우 바꾸기, 모노, 좌우 밸런스.
- **보컬 제거 (노래방)**: 가운데 보컬을 지워 반주를 만들고, 저음은 남기며 볼륨을 다시 맞춥니다. 스테레오 스튜디오 음원에 적합하며, 라이브나 모노에 가까운 음원은 효과가 제한적이고 미리보기에서 알려 줍니다.
- **볼륨**, **음량 평준화**, **키 변경**(위아래 6반음), **속도**(음악만), **페이드 인**, **페이드 아웃**.

### 화질 개선과 화면 비율 (영상)

- **화질 개선 (업스케일)**: 360p, 720p, 1080p를 1080p, 1440p, 4K로 키우고 노이즈 제거와 선명화를 적용합니다. AI 복원이 아니므로 사라진 디테일은 복구되지 않습니다. Mac의 하드웨어 HEVC 인코더를 사용하며 처리 시간은 영상 길이의 약 0.5~1배입니다.
- **화면 비율**: 원본, 16:9, 9:16, 1:1, 4:3, 4:5, 21:9. 원본과 비율이 다르면 화면은 늘어나지 않고, 남는 부분을 **검은 여백**, **흰 여백**, **흐린 배경**, **흐린 커버** 로 채우거나 **잘라서 채우기**(여백은 없지만 가장자리가 잘림)를 고를 수 있습니다.

### 가사 다운로드

1. **음악** 을 고르고 **가사도 다운로드** 를 켭니다.
2. **동기화 .lrc 파일 저장**(곡 옆에 저장되며 IINA 등에서 한 줄씩 표시)과 **곡 파일에 넣기**(Apple Music에 표시)를 고릅니다.
3. **중국어 글자체** 는 인터페이스에 맞춤, 변환 안 함, 번체로, 간체로 중에서 고를 수 있습니다.

가사는 공개 LRCLIB 데이터베이스에서 가져오며 번체와 간체 모두로 찾습니다. 곡을 자르면 동기화 가사의 시간도 함께 조정됩니다. 가사를 찾지 못해도 다운로드는 완료되며 목록에 '가사 없음'으로 표시됩니다.

### 모양과 화면 크기

- **화면 모드**: 시스템, 라이트, 다크.
- **테마 색상**: 7가지 기본 색상 또는 **사용자 지정 색상** 으로 두 색을 고릅니다. **그라데이션 사용** 을 켜고 끌 수 있고 방향도 고를 수 있습니다.
- **글꼴**, **글자 크기**, **버튼 크기**, **굵은 글씨**.
- **화면 배율**: 80% ~ 150%. `Command +`, `Command -`, `Command 0`으로도 바꿀 수 있습니다.
- **창 크기에 맞춰 확대/축소**: 창을 키우면 글자와 버튼도 커집니다.
- 사이드바는 도구 막대 버튼이나 `Control Command S`로 접고 펼칠 수 있습니다.

### 환경설정

- **언어**: 繁體中文, 简体中文, English, 日本語, 한국어 또는 시스템에 맞춤.
- **저장 위치** 와 **동시 다운로드 수**(기본값은 제한 없음. YouTube가 확인을 요구하면 2~3개로).
- **외부 도구**: yt-dlp와 ffmpeg 경로. **자동 감지** 로 없으면 설치. **yt-dlp 업데이트**.
- **YouTube 로그인**: 'Sign in to confirm you're not a bot'이 보이면 **브라우저의 YouTube 로그인 사용** 을 켭니다.
  - 'macOS가 TubeGrab의 브라우저 데이터 읽기를 허용하지 않습니다'라고 나오면 **시스템 설정 열기** 를 누르고 전체 디스크 접근 권한에 TubeGrab을 추가해 켠 뒤 앱을 다시 엽니다.
  - 또는 **cookies.txt 파일** 을 고르고 브라우저 확장 프로그램으로 내보낸 파일을 선택합니다(로그인 정보와 같으니 공유하지 마세요).
- **KKBOX Open API**, **Spotify API**(선택).

### 업데이트 확인과 문제 신고

- 실행할 때 하루에 한 번 GitHub에서 새 버전을 자동으로 확인합니다. **정보** 의 **지금 확인** 으로도 확인할 수 있습니다. 새 버전이 있으면 새로운 기능과 **업데이트 다운로드** 버튼이 표시됩니다.
- **정보** 에서 **문제 신고** 또는 **기능 제안** 을 누르면 버전과 환경 정보가 채워진 GitHub가 열립니다. 실패한 다운로드에도 **신고** 버튼이 있습니다. 보내기 전에 확인·수정할 수 있으며 사용자 이름은 포함되지 않습니다.

## 자주 묻는 질문

**'Sign in to confirm you're not a bot' 또는 HTTP 403이 나옵니다**
짧은 시간에 너무 많이 사용해 YouTube가 일시적으로 확인을 요구하는 것입니다. 몇 분 기다리거나, 환경설정에서 **yt-dlp 업데이트** 를 누르거나, **브라우저의 YouTube 로그인 사용** 을 켜세요.

**'could not find chrome cookies database'가 나옵니다**
macOS가 TubeGrab의 브라우저 데이터 읽기를 허용하지 않는 것입니다. 환경설정의 안내에 따라 전체 디스크 접근 권한을 허용하거나 cookies.txt 파일을 사용하세요.

**QuickTime에서 MP4가 열리지 않습니다**
4K 영상은 VP9나 AV1만 있는 경우가 많습니다. 1080p 이하를 고르거나 MKV와 [IINA](https://iina.io)를 사용하세요.

**Spotify나 Apple Music 재생목록을 읽지 못합니다**
재생목록이 공개되어 있어야 합니다. 사이트가 바뀌어 읽지 못하는 경우도 있습니다.

**중국어 노래의 가사를 찾지 못합니다**
곡명과 가수가 맞는지 확인하고(먼저 곡 정보에서 수정) **가사 찾기** 로 미리 확인하세요. 잘 알려지지 않은 일부 곡은 LRCLIB에 없습니다.

**보컬 제거 효과가 없습니다**
보컬 제거에는 스테레오 음원이 필요합니다. 라이브나 모노에 가까운 음원은 효과가 제한적입니다. 검색으로 '가수 - Topic'의 공식 음원을 찾아보세요.

## 개발자용

### 필요한 것

| 항목 | 용도 | 필요 여부 |
|---|---|---|
| macOS 14 이상 | 앱 실행 | 필수 |
| Xcode 15 이상 또는 Command Line Tools (Swift 5.10 이상) | 빌드 | 필수 |
| [yt-dlp](https://github.com/yt-dlp/yt-dlp) | 영상 분석과 다운로드 | 필수 (앱이 자동 설치 가능) |
| [ffmpeg](https://ffmpeg.org/) (ffprobe 포함) | 합치기, 변환, 자르기, 커버, 오디오·영상 처리 | 필수 (앱이 자동 설치 가능) |
| [deno](https://deno.com/) | 최신 yt-dlp가 YouTube를 완전히 지원하기 위한 JavaScript 런타임 | 권장 |

Swift 코드는 서드파티 패키지를 사용하지 않고 Apple 프레임워크(SwiftUI, AVKit, AVFoundation, AppKit, Foundation)만 사용합니다.

외부 도구를 직접 설치하려면:

```bash
brew install yt-dlp ffmpeg deno
```

### 빌드와 실행

```bash
swift run
```

`build/TubeGrab.app` 만들기:

```bash
./scripts/build-app.sh
```

Apple Silicon과 Intel 모두 지원:

```bash
./scripts/build-app.sh --universal
```

Xcode로 열기:

```bash
open Package.swift
```

### 릴리스 패키지 만들기

```bash
./scripts/package.sh 1.1
```

`dist/`에 `TubeGrab-1.1-macOS.dmg`, `TubeGrab-1.1-macOS.zip`, `SHA256SUMS.txt`가 만들어집니다(`dist/`는 git 대상이 아님). 앱의 업데이트 확인이 알려 줄 수 있도록 릴리스할 때마다 더 큰 버전 번호를 사용하세요.

### 앱 아이콘 바꾸기

새 이미지를 `assets/logo-source.png`로 저장하고(배경은 상관없음. 둥근 사각형을 자동으로 찾아 배경과 빛 번짐을 제거) 다음을 실행합니다.

```bash
swift scripts/make-icon.swift
```

`assets/AppIcon.png`와 `assets/AppIcon.icns`가 만들어지고 다음 빌드에서 자동으로 사용됩니다.

### 작동 원리

- `yt-dlp -J`로 영상 정보를 가져와 수정한 곡명과 가수를 `meta_title`, `meta_artist` 등의 필드에 쓴 뒤 `--load-info-json`으로 다운로드합니다. `--embed-metadata`가 파일에 기록합니다.
- 진행률: `--progress-template`으로 정해진 형식의 퍼센트를 출력합니다. 자르기할 때는 ffmpeg가 다운로드하며 `-progress pipe:2`의 `out_time_us`로 계산합니다. 영상, 오디오, 합치기를 하나의 연속된 전체 진행률로 합칩니다.
- 오디오 도구, 화질 개선, 화면 비율은 다운로드 후 ffmpeg 한 번으로 처리합니다. '설정 적용 후' 미리보기도 같은 처리를 사용합니다.
- MP3 가사는 앱이 ID3의 USLT 프레임에 직접 씁니다(ffmpeg는 Apple Music이 읽지 않는 TXXX 프레임만 쓸 수 있기 때문). 다른 형식은 lyrics 태그를 사용합니다.
- Spotify와 Apple Music은 공개 페이지의 곡명과 가수만 읽고, KKBOX는 공식 Open API를 사용합니다. 그다음 YouTube에서 검색합니다.
