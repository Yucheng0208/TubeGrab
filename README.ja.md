# TubeGrab

[繁體中文](README.md) | [简体中文](README.zh-Hans.md) | [English](README.en.md) | **日本語** | [한국어](README.ko.md)

TubeGrab は Swift と SwiftUI で作られた macOS 用の動画・音楽ダウンローダーです。URL を貼り付けるか曲名を入力し、選ぶだけでダウンロードできるシンプルな画面を目指しています。yt-dlp や ffmpeg などのオープンソースツールを使いやすい Mac アプリにまとめる方法を示す、学習用のサンプルプロジェクトです。

## 機能一覧

| 機能 | 説明 |
|---|---|
| 動画・音楽のダウンロード | YouTube と yt-dlp が対応する数千のサイト。動画：MP4、MOV、MKV、WEBM（360p から 4K）。音楽：MP3、M4A、AAC、FLAC、ALAC、WAV、OPUS、OGG |
| 曲を検索 | 曲名、アーティスト、覚えている歌詞の一節で検索。結果に「公式」「おすすめ」を表示し、試聴も可能 |
| 一括ダウンロード | YouTube プレイリスト、Spotify、Apple Music、KKBOX のプレイリストやアルバム、または CSV・TXT・XLSX ファイルの読み込み |
| 最適な動画を自動選択 | レーベルや公式チャンネルを優先し、見つからない場合は再生回数が最も多い動画を選択 |
| 曲情報 | ファイル名、曲名、アーティスト、アルバム、年、ジャンルを自動入力。すべて編集でき、ネット上の曲情報も参考にできます |
| 歌詞 | 同期歌詞（.lrc）のダウンロード、曲ファイルへの埋め込み、全歌詞の書き出し、繁体字・簡体字の変換 |
| プレビューとトリミング | 動画のプレビュー、一部分だけのダウンロード、設定を適用した実際の結果のプレビュー |
| オーディオツール | 左右チャンネル、バランス、ボーカル除去、音量、音量の均一化、キー変更、速度、フェードイン・アウト |
| 動画の加工 | 画質向上（1080p から 4K に拡大）、アスペクト比の変更（黒帯、白帯、ぼかし背景、ぼかしカバー、切り抜き） |
| 楽譜を探す | ギター TAB、コード、五線譜、数字譜、ピアノ譜をワンクリックで検索 |
| ダウンロード一覧 | 全体と各項目の進行状況（割合、速度、残り時間）。キャンセル、再試行、削除、ファイルを直接開く |
| 画面 | 繁體中文、简体中文、English、日本語、한국어。ダーク、ライト、システム。カスタムテーマカラーとグラデーション。フォント、文字サイズ、ボタンの大きさ、表示倍率 |
| どんなウインドウサイズでも | 自由にサイズ変更やフルスクリーンが可能。文字とボタンもウインドウに合わせて変わり、狭いときは縦並びのレイアウトになります |
| ツールの自動インストール | yt-dlp や ffmpeg が見つからない場合はワンクリックでインストール |
| アップデートの確認 | GitHub で新しいバージョンを確認 |

## ダウンロードとインストール

1. [Releases](../../releases) ページから `TubeGrab-バージョン-macOS.dmg`（または `.zip`）をダウンロードします。
2. `.dmg` を開き、**TubeGrab** を **アプリケーション** フォルダにドラッグします。
3. 初回起動時は、アプリケーションフォルダで TubeGrab を **右クリックして「開く」を選び、もう一度「開く」** を押します。
   Apple の公証を受けていないため、初回だけ macOS が確認します。次回からはダブルクリックで開けます。
4. 「壊れているため開けません」と表示された場合は、ターミナルで次を実行してください。

   ```bash
   xattr -dr com.apple.quarantine /Applications/TubeGrab.app
   ```

**動作環境**：macOS 14 Sonoma 以降。Apple シリコンと Intel の Mac に対応しています。

**アップデート**：新しい `.dmg` をダウンロードし、TubeGrab をアプリケーションフォルダにドラッグして置き換えてください。設定は保持されます。

## 初めて使うとき

1. TubeGrab を開きます。上部に「初回：ダウンロードツールが必要です」と表示されたら **インストール** を押し、1〜3 分待ちます。
   - Homebrew がある場合は `brew install yt-dlp ffmpeg deno` を実行します。
   - Homebrew がない場合は、公式のリリースページから `~/Library/Application Support/TubeGrab/bin` にダウンロードします。
2. **外観** で表示モード、配色、文字サイズを選びます。
3. **環境設定** で表示言語と保存先（初期設定は「ダウンロード」フォルダ）を選びます。

## 使い方

サイドバーは 3 つのグループに分かれています。

| グループ | ページ | 用途 |
|---|---|---|
| ダウンロード | 新規ダウンロード | 動画の URL を貼り付け、形式やプレビュー、トリミング、情報の編集をしてダウンロード |
| | 曲を検索 | 曲名やアーティストで検索 |
| | 歌詞で探す | 歌詞の一節しか覚えていないとき |
| | 一括ダウンロード | プレイリストをまとめてダウンロード |
| | ダウンロード一覧 | 進行状況と完了したファイル |
| 設定 | 外観 | 表示モード、配色、フォント、大きさ |
| | 環境設定 | 言語、保存先、外部ツール、YouTube ログイン、API キー |
| サポート | ヘルプ | 各機能の操作手順（検索可能） |
| | このアプリについて | バージョン、アップデートの確認、不具合の報告、免責事項 |

入力欄に貼り付けた内容は自動的に適切なページへ送られます。単一の動画は新規ダウンロード、プレイリストの URL は一括ダウンロード、テキストは曲を検索へ移動します。

### 新規ダウンロード（動画・曲を 1 つ）

1. YouTube などで動画の URL をコピーし、**新規ダウンロード** で **貼り付け** を押します（入力欄に貼り付けて **読み込む** でも可）。`https://` は省略できます。
2. **動画** か **音楽（音声のみ）** を選びます。
3. 形式と品質を選びます。
   - 動画：MP4、MOV、MKV、WEBM、360p から 4K。Mac や iPhone で再生するなら MP4 がおすすめです。
   - 音楽：MP3、M4A、FLAC、ALAC、WAV など。普段使いなら MP3 320k で十分です。
4. 必要に応じて、下のオーディオツール、トリミング、曲情報を調整します。
5. **ダウンロードに追加** を押し、ダウンロード一覧で進行状況を確認します。

URL ではなく文字を入力すると、入力欄の下に **曲名・アーティスト** と **歌詞で** の 2 つのボタンが表示され、押すと検索が始まります。

### プレビュー、トリミング、設定適用後のプレビュー

- 動画を読み込むと、プレビュープレーヤーが自動で表示されます。
- **一部分だけダウンロード** をオンにして開始・終了をドラッグするか、再生中に **現在位置を開始に** / **現在位置を終了に** を押します。
- プレーヤー上部で **設定適用後** に切り替えると、本番と同じ処理で短い区間（トリミング範囲は最大 30 秒、それ以外は現在位置から 20 秒）を生成し、形式、オーディオツール、画質向上、アスペクト比の実際の効果を確認できます。**自動で更新** がオンなら、設定を変えると自動で作り直します。
- プレビューの下に保存されるファイル名と曲情報が表示されます。

### ファイル名、曲情報、歌詞のプレビュー

- ファイル名、曲名、アーティスト、アルバム、アルバムアーティスト、年、ジャンルは YouTube の情報が初期値です。すべて編集でき、ファイルのタグに書き込まれます。
- **ネット上の曲情報（参考）**：Apple Music のカタログを検索し、カバー、アルバム、年、トラック番号付きの候補を表示します。**適用** を押すまで変更されません。**YouTube の情報に戻す** で元に戻せます。
- **歌詞**：**歌詞を探す** でプレビューし、同期歌詞とテキストを切り替えられます。**歌詞をコピー**、**.lrc を書き出す**、**全歌詞を .txt で書き出す** が使えます。
- **楽譜を探す**：ギター TAB・コード（Ultimate Guitar、91譜）、五線譜（MuseScore）、数字譜、ピアノ譜の検索結果を開きます。Web ページを開くだけで、楽譜はダウンロードしません。

### 曲を検索・歌詞で探す

1. **曲を検索** で「アーティスト 曲名」を入力します。**歌詞で探す** では覚えている歌詞を 1〜2 行入力します。
2. 「公式」はレーベルやアーティストのチャンネル、「おすすめ」はアプリが選んだ最適な動画です。
3. サムネイルの再生ボタンで試聴でき、下部に再生バーが表示されます。
4. **これを選ぶ** で新規ダウンロードに移って細かく設定するか、**音楽として保存** で既定の設定のまますぐに保存します。

### 一括ダウンロード

1. **一括ダウンロード** でプレイリストやアルバムの URL を貼り付け、**読み込む** を押します。

   | ソース | 説明 |
   |---|---|
   | YouTube プレイリスト | `youtube.com/playlist?list=...`。`watch?v=...&list=RD...` のような自動ミックスは単一の動画として扱います |
   | Spotify | 公開プレイリストやアルバム。API キーなしでは約 50〜100 曲まで |
   | Apple Music | 公開プレイリストやアルバム |
   | KKBOX | 環境設定に無料の KKBOX Open API キーが必要。または曲リストの貼り付けを使用 |

2. **曲リストを貼り付け** を押し、1 行に 1 曲ずつ入力することもできます。

   ```text
   アーティスト - 曲名
   曲名 / アーティスト
   1. アーティスト - 曲名 4:22
   ```

3. **ファイルを読み込む（CSV / TXT / XLSX）** を押すか、ファイルをページにドロップします。曲名、アーティスト、アルバム、長さの列を自動で見つけます（Spotify の `Track Name`、`Artist Name(s)` など）。見出しがない場合は 1 列目を曲名、2 列目をアーティストとして扱います。
4. ダウンロードする曲にチェックを付けて形式を選び、**すべて自動ダウンロード** か **選択した曲をダウンロード** を押します。

各曲は YouTube で最適な動画を探します。カバー、カラオケ、リミックスなどを除外し、「アーティスト - Topic」チャンネル、VEVO、レーベル、アーティストの公式チャンネルを優先します。どれもない場合のみ再生回数が最も多い動画を選びます。

### ダウンロード一覧

- 上部の円が全体の進行状況です。各項目に割合、現在の段階、ダウンロード済みのサイズ、速度、残り時間が表示されます。
- ダウンロード中は **キャンセル**、失敗したら **再試行** または **報告**。完了後はサムネイルかタイトルをクリック、または行をダブルクリックで開きます。
- 再生できるアプリで自動的に開きます。macOS が対応する形式は既定のアプリで、MKV、WEBM、OPUS などは IINA や VLC（インストール済みの場合）で開きます。
- 既定の保存先は「ダウンロード」フォルダで、環境設定で変更できます。

### オーディオツール

新規ダウンロードまたは一括ダウンロードで **オーディオツール** を開きます。

- **チャンネル**：ステレオ、左のみ、右のみ、左右入れ替え、モノラル、左右バランス。
- **ボーカル除去（カラオケ）**：中央のボーカルを打ち消して伴奏を作り、低音を残して音量を補正します。ステレオのスタジオ音源向けで、ライブやモノラルに近い音源では効果が限られ、プレビューで警告が表示されます。
- **音量**、**音量を均一化**、**キー変更**（上下 6 半音）、**速度**（音楽のみ）、**フェードイン**、**フェードアウト**。

### 画質向上とアスペクト比（動画）

- **画質向上（アップスケール）**：360p、720p、1080p を 1080p、1440p、4K に拡大し、ノイズ除去とシャープ化を行います。AI による復元ではないため、失われた細部は戻りません。Mac のハードウェア HEVC エンコーダを使い、処理時間は動画の長さの約 0.5〜1 倍です。
- **アスペクト比**：オリジナル、16:9、9:16、1:1、4:3、4:5、21:9。元の比率と違う場合でも映像は歪まず、余白は **黒帯**、**白帯**、**ぼかし背景**、**ぼかしカバー** で埋めるか、**切り抜き**（帯なし、ただし端が切れます）を選べます。

### 歌詞のダウンロード

1. **音楽** を選び、**歌詞もダウンロード** をオンにします。
2. **同期歌詞 .lrc を保存**（曲と同じ場所に保存され、IINA などで 1 行ずつ表示）と **曲ファイルに埋め込む**（ミュージックで表示）を選びます。
3. **中国語の字体** は、表示言語に合わせる、変換しない、繁体字に、簡体字に、から選べます。

歌詞はオープンな LRCLIB データベースから取得し、繁体字と簡体字の両方で照合します。トリミングすると同期歌詞の時間も合わせて調整されます。歌詞が見つからなくてもダウンロードは完了し、一覧に「歌詞なし」と表示されます。

### 外観と表示サイズ

- **表示モード**：システム、ライト、ダーク。
- **テーマカラー**：7 種類のプリセット、または **カスタムカラー** で 2 色を選択。**グラデーションを使う** のオン・オフと方向を選べます。
- **フォント**、**文字サイズ**、**ボタンの大きさ**、**太字**。
- **表示倍率**：80% から 150%。`Command +`、`Command -`、`Command 0` でも変更できます。
- **ウインドウに合わせて拡大縮小**：ウインドウを大きくすると文字とボタンも大きくなります。
- サイドバーはツールバーのボタンまたは `Control Command S` で開閉できます。

### 環境設定

- **表示言語**：繁體中文、简体中文、English、日本語、한국어、またはシステムに合わせる。
- **保存先** と **同時ダウンロード数**（初期設定は無制限。YouTube が確認を求める場合は 2〜3 に）。
- **外部ツール**：yt-dlp と ffmpeg のパス。**自動検出** で見つからなければインストール。**yt-dlp を更新**。
- **YouTube ログイン**：「Sign in to confirm you're not a bot」と表示されたら **ブラウザの YouTube ログインを使う** をオンにします。
  - 「macOS が TubeGrab にこのブラウザのデータの読み取りを許可していません」と表示された場合は **システム設定を開く** を押し、フルディスクアクセスに TubeGrab を追加してオンにし、アプリを開き直します。
  - または **cookies.txt ファイル** を選び、ブラウザの拡張機能で書き出したファイルを指定します（ログイン情報と同じなので共有しないでください）。
- **KKBOX Open API**、**Spotify API**（任意）。

### アップデートの確認と不具合の報告

- 起動時に 1 日 1 回、GitHub で新しいバージョンを自動確認します。**このアプリについて** の **今すぐ確認** でも確認できます。新しいバージョンがあると更新内容と **アップデートをダウンロード** ボタンが表示されます。
- **このアプリについて** の **不具合を報告** または **機能の提案** を押すと、バージョンと環境情報が入力された状態で GitHub が開きます。失敗したダウンロードにも **報告** ボタンがあります。送信前に内容を確認・編集でき、ユーザー名は含まれません。

## よくある質問

**「Sign in to confirm you're not a bot」や HTTP 403 が表示される**
短時間に使いすぎたため、YouTube が一時的に確認を求めています。数分待つか、環境設定で **yt-dlp を更新** を押すか、**ブラウザの YouTube ログインを使う** をオンにしてください。

**「could not find chrome cookies database」と表示される**
macOS が TubeGrab にブラウザのデータの読み取りを許可していません。環境設定の手順でフルディスクアクセスを許可するか、cookies.txt ファイルを使ってください。

**QuickTime で MP4 が開けない**
4K 動画は VP9 や AV1 しかないことが多いです。1080p 以下を選ぶか、MKV と [IINA](https://iina.io) を使ってください。

**Spotify や Apple Music のプレイリストが読み込めない**
プレイリストが公開されている必要があります。サイトの変更で読み込めなくなることもあります。

**中国語の曲の歌詞が見つからない**
曲名とアーティストが正しいか確認し（先に曲情報で修正）、**歌詞を探す** でプレビューしてください。一部のあまり知られていない曲は LRCLIB にありません。

**ボーカル除去の効果がない**
ボーカル除去にはステレオ音源が必要です。ライブやモノラルに近い音源では効果が限られます。検索で「アーティスト - Topic」の公式音源を探してみてください。

## 開発者向け

### 必要なもの

| 項目 | 用途 | 必要性 |
|---|---|---|
| macOS 14 以降 | アプリの実行 | 必須 |
| Xcode 15 以降、または Command Line Tools（Swift 5.10 以降） | ビルド | 必須 |
| [yt-dlp](https://github.com/yt-dlp/yt-dlp) | 動画の解析とダウンロード | 必須（アプリが自動インストール可能） |
| [ffmpeg](https://ffmpeg.org/)（ffprobe を含む） | 結合、変換、トリミング、カバー、音声・動画の加工 | 必須（アプリが自動インストール可能） |
| [deno](https://deno.com/) | 新しい yt-dlp が YouTube に完全対応するための JavaScript ランタイム | 推奨 |

Swift のコードはサードパーティのパッケージを使わず、Apple のフレームワーク（SwiftUI、AVKit、AVFoundation、AppKit、Foundation）のみを使用しています。

外部ツールを手動でインストールする場合：

```bash
brew install yt-dlp ffmpeg deno
```

### ビルドと実行

```bash
swift run
```

`build/TubeGrab.app` を作成：

```bash
./scripts/build-app.sh
```

Apple シリコンと Intel の両方に対応：

```bash
./scripts/build-app.sh --universal
```

Xcode で開く：

```bash
open Package.swift
```

### リリース用のパッケージ作成

```bash
./scripts/package.sh 1.1
```

`dist/` に `TubeGrab-1.1-macOS.dmg`、`TubeGrab-1.1-macOS.zip`、`SHA256SUMS.txt` が作成されます（`dist/` は git の対象外）。アプリのアップデート確認が通知できるよう、リリースごとに大きいバージョン番号を使ってください。

新しい画像を `assets/logo-source.png` として保存し（背景は自由。角丸の四角を自動で見つけ、背景と光彩を取り除きます）、次を実行します。

```bash
swift scripts/make-icon.swift
```

`assets/AppIcon.png` と `assets/AppIcon.icns` が作成され、次のビルドで自動的に使われます。

### 仕組み

- `yt-dlp -J` で動画の情報を取得し、編集した曲名やアーティストを `meta_title`、`meta_artist` などのフィールドに書き込んでから `--load-info-json` でダウンロードします。`--embed-metadata` がファイルに書き込みます。
- 進行状況：`--progress-template` で決まった形式の割合を出力します。トリミング時は ffmpeg がダウンロードし、`-progress pipe:2` の `out_time_us` で計算します。映像、音声、結合をひとつの連続した全体の進行状況にまとめています。
- オーディオツール、画質向上、アスペクト比はダウンロード後に 1 回の ffmpeg 処理で行います。「設定適用後」のプレビューも同じ処理を使います。
- MP3 の歌詞は ID3 の USLT フレームにアプリが直接書き込みます（ffmpeg はミュージックが読まない TXXX フレームしか書けないため）。その他の形式は lyrics タグを使います。
- Spotify と Apple Music は公開ページの曲名とアーティストだけを読み取り、KKBOX は公式の Open API を使います。その後 YouTube で検索します。
